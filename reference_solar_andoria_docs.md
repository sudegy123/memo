**Solar Smart Advisor** (`Documents/Solar-Smart-Advisor`, copy `Solar-Smart-Advisor - New Design`): vanilla JS, no build, no deps, Arabic RTL default, Cairo font, works offline for Sudan. 10-step wizard (Welcome, Property, Info, Devices, Summary, Recommendation, Packages, Savings, Trust, CTA). Modules: `StateManager` singleton (get/setState/subscribe), `CalcEngine` pure functions only (no DOM/state), devices.json (33 devices, 8 categories), router, charts (SVG). Formulas: daily Wh = sum(W*h*qty)*1.15; battery = Wh*autonomy/DoD/temp; panels = Wh/PSH/eff*margin; MPPT = array W/V*1.25; inverter = max(peak*1.2, surge*0.7). Sudan constants: PSH Khartoum 5.5-6.0, eff 75%, margin 25%, derate 10%, DoD 80% LiFePO4 / 50% lead-acid. WhatsApp CTA carries full spec. DECISION-TREE.md (36KB) = researched device tree spec for devices.json v2 (Sudan context: 220V/380V 50Hz, motor surge multipliers). Built by Sudegy. See [[feedback-mobile-css-cache-busting]] for the phone caching trap hit here.

**ANDORIA design system v1.0** (tokens in `variables.css`, never hardcode hex): bg `#071A12`, surface `#0B2419`, surface2 `#10301F`, surface3 `#163B27`, gold `#F2B632` -> gold-light `#FFC94A`, text white / muted `#D9D9D9` / dim `#8FA398`, gold hairlines `rgba(242,182,50,.12/.28)`; semantic success `#34D399`, warning `#FBBF24`, danger `#F0554F` for state only; WhatsApp green `#25D366` only on WhatsApp CTA. NEVER blue/purple/cyan/pink. Logo = diagonal red-orange-gold tri-stripe + ANDORIA wordmark, always LTR even in RTL. Radius: pill buttons/tabs, 24-32px hero cards, 16px cards, 8px inputs. Borders over shadows; gold glow only under primary CTA. Icon badges = circular hairline gold ring. Headlines two-tone (white + gold clause). Buttons: primary gold gradient pill with dark-green text; secondary 1.5px gold border; ghost dark emerald.

**Dr. Mazin motion rules** (DESIGN-EVOLUTION.md; obsidian `#15130F` + gold): lit-not-flat dark (one breathing bloom + grain/vignette); edge-light + warm shadows (never pure black); NO spinners (gold breathing light, no rotation); calm settle only (no bounce); every decorative layer aria-hidden + off under reduced motion; quality tiers HIGH/MEDIUM/LOW/MIN in `quality.js` (`html[data-quality]`, SUDEGY_Q) with hysteresis (tier must read same twice ~180ms apart). Android Chrome bug class: decorative `position:fixed` layers drift during URL-bar collapse; fix = `absolute` inside relative ancestors, one stable `svh`, no `background-attachment:fixed` on touch, remove `left:50%+translateX(-50%)` centering (use `left:0;right:0;margin-inline:auto`), and ALWAYS grep for duplicate `@keyframes` names (the later one silently wins and hid the real bug). Face scan uses MediaPipe FaceDetector and fails closed. Business logic files stay byte-identical (SHA-256 vs zip); presentation only. Hero 3D rules in [[project-dr-mazin-auto-intro]].

**Miniman Commerce OS** (`Documents/miniman-main/backend/README.md`): DB is source of truth, browser sends no trusted price/stock. Stock per variant (stock, reserved, available = stock - reserved, damaged separate); every change is an append-only ledger row via `_inv_move`; order PENDING->CONFIRMED->PROCESSING->READY_FOR_SHIPMENT->SHIPPED->DELIVERED, cancel until READY; returns restock or damaged; `place_order` locks rows (no double-sell, tested 25 buyers/1 pair) + idempotency key; reconciliation rebuilds stock from ledger; RLS on, anon can only call store_catalog/store_product/store_config/store_cart_check/place_order/track_order; COD only; go-live steps in the README. Details: [[project-miniman-commerce-os]].

**agy / Gemini** (`Documents/agy-gemini/*.md`): same as [[reference-antigravity-cli-gemini]] plus: image tool does NOT refuse real brands (made a real Nike Air Max and Fronius logo), so prompt "no logos, no brand names" and inspect; text inside images is garbled; trusted folders live in `~/.gemini/antigravity-cli/settings.json` `trustedWorkspaces`; debug denied tools in `brain/<id>/.system_generated/logs/transcript_full.jsonl`.
