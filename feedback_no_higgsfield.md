Do not use any Higgsfield tool (`generate_3d`, `generate_image`, etc.), even when it looks like the best fit for a task (e.g. generating a missing 3D model).

**Why:** User explicitly said "never use higgsfield" mid-task while I was about to use its `generate_3d` capability to create a 3D model.

**How to apply:** When a task would normally reach for Higgsfield (3D generation, image/video/audio generation), find another route instead — search for existing free/CC0 assets (e.g. Poly Pizza), ask the user to supply/download an asset, or use a different tool entirely. See [[project_soda_landing_page]] for an example where this came up.
